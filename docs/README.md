# Проект «Математические и геометрические вычисления»

## Общее описание решения

Данный проект представляет собой набор модулей для выполнения базовых математических и геометрических расчетов. Проект включает функции для вычисления площадей и периметров основных геометрических фигур (круг, прямоугольник, квадрат, треугольник). 

Каждая группа функций выделена в отдельный модуль, что обеспечивает чистоту кода и удобство повторного использования.

**Структура модулей:**
- `circle.py` — вычисления для круга.
- `rectangle.py` — вычисления для прямоугольника.
- `square.py` — вычисления для квадрата.
- `triangle.py` — вычисления для треугольника.
---
### Модуль `circle.py`

#### `area(r)`
Вычисляет площадь круга.

**Параметры:** `r`: радиус круга.

**Возвращаемое значение:**  площадь круга.

**Пример вызова:**
```python
from circle import area

print(area(5))   # 78.53981633974483
print(area(10))  # 314.1592653589793
```

#### `perimeter(r)`
Вычисляет периметр (длину окружности) круга.

**Параметры:**
- `r`: радиус круга.

**Возвращаемое значение:** периметр круга.

**Пример вызова:**
```python
from circle import perimeter

print(perimeter(5))   # 31.41592653589793
print(perimeter(10))  # 62.83185307179586
```

---

### Модуль `rectangle.py`

#### `area(a, b)`
Вычисляет площадь прямоугольника.

**Параметры:**
- `a`: длина первой стороны.
- `b`: длина второй стороны.

**Возвращаемое значение:** площадь прямоугольника.

**Пример вызова:**
```python
from rectangle import area

print(area(3, 4))   # 12
print(area(5, 7))   # 35
```

#### `perimeter(a, b)`
Вычисляет периметр прямоугольника.

**Параметры:**
- `a`: длина первой стороны.
- `b`: длина второй стороны.

**Возвращаемое значение:** периметр прямоугольника.

**Пример вызова:**
```python
from rectangle import perimeter

print(perimeter(3, 4))   # 14
print(perimeter(5, 7))   # 24
```

---

### Модуль `square.py`

#### `area(a)`
Вычисляет площадь квадрата.

**Параметры:**
- `a`: длина стороны квадрата.

**Возвращаемое значение:** площадь квадрата.

**Пример вызова:**
```python
from square import area

print(area(4))   # 16
print(area(7))   # 49
```

#### `perimeter(a)`
Вычисляет периметр квадрата.

**Параметры:**
- `a`: длина стороны квадрата.

**Возвращаемое значение:** периметр квадрата.

**Пример вызова:**
```python
from square import perimeter

print(perimeter(4))   # 16
print(perimeter(7))   # 28
```

---

### Модуль `triangle.py`

#### `area(a, h)`
Вычисляет площадь треугольника.

**Параметры:**
- `a`: длина основания треугольника.
- `h`: высота треугольника.

**Возвращаемое значение:** площадь треугольника.

**Пример вызова:**
```python
from triangle import area

print(area(6, 4))   # 12.0
print(area(10, 5))  # 25.0
```

#### `perimeter(a, b, c)`
Вычисляет периметр треугольника.

**Параметры:**
- `a`: длина первой стороны.
- `b`: длина второй стороны.
- `c`: длина третьей стороны.

**Возвращаемое значение:** периметр треугольника.

**Пример вызова:**
```python
from triangle import perimeter

print(perimeter(3, 4, 5))   # 12
print(perimeter(6, 8, 10))  # 24
```
